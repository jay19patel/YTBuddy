Connect Google first

YTStudio needs a Google OAuth client to sign in to your channels. It takes about five minutes, once.

  1. Open Google Cloud Console and create a project.
  2. Enable YouTube Data API v3 under APIs & Services, Library.
  3. Set up the OAuth consent screen (External) and add your Gmail addresses as test users.
  4. Create an OAuth client ID of type Web application with redirect URI http://localhost:8000/oauth2callback.
  5. Download the JSON, save it as YTStudioCred.json next to main.py, and reload this page.
