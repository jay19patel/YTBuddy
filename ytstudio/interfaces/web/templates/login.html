Connect Google first

  2. Enable YouTube Data API v3 and YouTube Analytics API.
  3. Set up the OAuth consent screen (External) and add your Gmail addresses as test users.

  5. Download the client JSON, save it as YTStudioCred.json next to main.py, then restart.
